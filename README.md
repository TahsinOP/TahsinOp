## Tahsin Khan

Robotics engineer at the ERTS Lab (e-Yantra), IIT Bombay.

I am interested in making robots reliable in the real world by combining structure we understand (geometry, physics, estimation) with learning for what we can't model. In particular:

- **Hybrid model-based and learned methods** for estimation and control
- **Multi-robot systems** that cooperate using only onboard, local sensing
- **Efficient perception** that runs on small onboard computers

Currently working on cooperative transport with two mobile manipulators that localise each other through the grasp, with no motion capture or shared map.
